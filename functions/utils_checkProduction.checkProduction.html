Function checkProduction

현재 환경이 프로덕션인지 확인하는 유틸리티 함수입니다.

Remarks

  • window.location.origin을 기준으로 프로덕션 환경을 판단합니다.
  • troublepainter.site 도메인이 포함되어 있으면 프로덕션으로 간주합니다.

Example

if (isProduction()) {
  // 프로덕션 환경에서만 실행될 코드
}
